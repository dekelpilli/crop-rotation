Harvest Crop Rotation Optimiser

Assumes every other Harvest Atlas passive is already allocated, including the Crop Rotation keystone. Reaching Crop Rotation requires fully allocating one colour's branch (two 10% nodes plus one 25% notable, all three — a locked-in 45% reduced chance to grow that colour), so at least one colour is always at 45%. The other two colours can each independently sit at 0%, 10%, 20%, 25%, 35%, or 45% (the 25% notable can be taken alone, without either 10% node). An exact solver plays every possible Grove optimally (crop pairs, wilting, and the tier-upgrade mini-game, reacting correctly to lucky and unlucky outcomes) to find the reduction levels that maximise expected divine value per Grove — and the same solver is available below as a step-by-step advisor for your actual Grove.

Mechanics modelled

  • Reaching Crop Rotation locks one colour to 45% reduced chance to grow (both 10% nodes + the 25% notable). The other two colours are each independently 0/10/20/25/35/45% — six levels, since the 25% notable can be taken on its own without either 10% node — renormalised into spawn weights (weight = 1 − reduction).
  • A Grove has 3, 4, or 5 crop pairs (29% / 47% / 24%, matching the "chance to contain an additional Harvest" passive already assumed taken). Each pair's two crops each independently roll a colour from the current weights.
  • Every crop starts as 23 Tier 1 seeds. Harvesting any crop gives every seed in every crop of a different colour an independent chance to step up one tier: T1→T2 25%, T2→T3 20%, T3→T4 5% (T16-map rates, per Prohibited Library Discord data).
  • Activating one crop in a pair destroys the other unless it rolls a 10% "chance for the unchosen Crop to not wilt" (Heart of the Grove, assumed taken).
  • Harvest order is chosen by an exact solver, not a fixed heuristic: divine value is a linear function of tier counts, and the expected-value tier-upgrade transition is also linear, so a crop's expected value is fully determined by its current tier counts and how many more cross-colour "trigger rounds" it lives through — order-independent. That collapses the problem to a small expectimax search (memoized on the set of surviving crops and their tiers) that branches only on the one real chance event, the wilt roll, and always picks whichever harvest maximises total expected remaining value. It correctly discovers, for example, that with several pairs of one colour and only one crop of another, harvesting the abundant colour first to fund upgrades and cashing in the scarce one last (once it's absorbed every prior trigger) beats protecting a nominal "target" colour by rote. The ranked table below runs this solver against randomly drawn Grove compositions, starting every crop fresh, and averages the exact optimal value of each. The Grove advisor panel runs the same solver interactively against your actual Grove, one real decision at a time — and after every trigger it asks you to confirm the actual observed T2–T4 counts (pre-filled with the expected outcome as a starting guess) rather than silently assuming every upgrade roll lands on average, so its recommendations track your real Grove even after a lucky or unlucky swing.
  • Lifeforce value per seed tier (at 0% pack size): T1 ≈ 0.145, T2 ≈ 1.85, T3 = 47, T4 = 235 — derived from monster-spawn chance × drop chance × average stack size per tier. Pack size scales T1–T3 (more monsters per seed); T4 seeds always spawn exactly one boss monster regardless of pack size.

Deliberately not modelled

  • Map IIQ and "increased Lifeforce quantity" Atlas passives — these scale every tier and colour by the same multiplier, so they don't change which configuration is best, only the absolute divine figure. Left out to keep inputs focused on decisions that matter.
  • Duplicated monsters / duplicated Lifeforce passives — roughly flat multipliers on total yield, same reasoning.
  • Non-uniform pair colour assignment — each of a pair's two crops is drawn independently; there's no confirmed rule forcing the two members of a pair to differ in colour.
  • "Imbued Harvest" map device craft — a per-map choice (not an Atlas passive) that would raise wilt-survival and seed-count further; out of scope for a tree-configuration tool since it's a separate, per-map decision.
